# 0.8 leftovers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close everything left open from 0.8 and earlier (except the security review) so CI is green and the roadmap's 0.8-and-earlier lists are empty.

**Architecture:** Fourteen independent fixes on branch `fix-0.8.1`: test and platform fixes, two evaluation-order rules made exact in both backends, four new `Fs` methods, runtime and build improvements, review minors, and incremental checking in the language server.

**Tech Stack:** OCaml 5 (src/), Limen (selfhost/, src/std/), C11 runtime (src/runtime/), dune.

**Spec:** `docs/superpowers/specs/2026-11-26-0.8-leftovers-design.md`

## Global Constraints

- Every language or compiler change goes into both compilers (`src/` and `selfhost/`) and both backends; the self-hosted compiler stays at the bootstrap fixed point.
- Process (the user's decision): each task runs `dune build`, the focused tests it names (`LIMEN_TEST_ONLY=<names> dune exec ./test/test_limen.exe`), and, when it touches `selfhost/`, builds the self-hosted compiler with the OCaml one (`LIMEN_CACHE=off _build/default/bin/main.exe build selfhost/limen.lmn -o <scratch>/stage1`). The full suite, `selfhost/check.sh`, the bootstrap and Linux run once, at the end (Task 15).
- Commit messages: plain, no `Co-Authored-By`, no "Generated with", no attribution of any kind. British spelling, no em dashes, no emojis, in messages, comments and docs. Commit locally per task; never push.
- RTK may rewrite shell commands; `rtk proxy <cmd>` runs one raw.
- The runtime still needs nothing but a C compiler and libc (and the libraries it already links); macOS and Linux, x86-64 and arm64.
- SPEC.md describes every behaviour change in the same commit.

## Review Focus

1. Place evaluation with a map key whose expression has a side effect (`m[side("k")] = 1`): the side effect runs once. Test `place-once-map` in Task 4.
2. `Fs.copy` onto an existing file, and onto a link inside the grant pointing outside: the first replaces the file, the second is refused like every other write through a link. Tests `fs-copy-replace` and `fs-copy-link-out` in Task 6.
3. A cancelled sort leaves the list exactly as it was (not half-sorted), natively and in the interpreter. Test `sort-cancel-keeps` in Task 7.
4. More than 64 concurrent blocking foreign calls in the interpreter: all complete, none fails to start. Test `ffi-blocking-many` in Task 8.
5. A function referenced only through a `dyn` vtable or a closure in another piece is not made `static`. Test `split-static-vtable` in Task 9.

### Task 6: `Fs.copy`, `touch`, `set_executable`, `read_link`

**Files:** the end-to-end list for a new `Fs` method: `src/check.ml` (~771-777), `selfhost/builtins.lmn` (~134-147), `src/runtime/limen_sandbox.h` (new `w_fs_*` helpers next to the existing ones), `src/runtime/limen_rt.c` and `limen_rt.h` (`Cap_fs_copy`, `Cap_fs_touch`, `Cap_fs_set_executable`, `Cap_fs_read_link`), `src/cgen.ml` (~1137-1188) and `selfhost/cgen.lmn` (~1880-1937), `src/ffi_stubs.c` (`limen_fs_op` new op codes 10-13), `src/caps.ml`, `src/interp.ml` (~3193-3218), `SPEC.md` (Fs table ~1437-1445), `selfhost/native.lmn` (`copy`, `cached_file`, the touch at ~685), `selfhost/bootstrap.sh`, `selfhost/check.sh`, `selfhost/README.md`. Tests: `test/test_limen.ml` beside the Fs tests; `selfhost/tests/c/caps.lmn`.

**Interfaces (Limen):**
- `fs.copy(from: Str, to: Str) -> Result[(), IoError]`: copies the bytes and the executable bit; replaces `to` if it exists; refused on a read-only `Fs`.
- `fs.touch(path: Str) -> Result[(), IoError]`: sets the modified time to now; creates an empty file if missing; refused on a read-only `Fs`.
- `fs.set_executable(path: Str, on: Bool) -> Result[(), IoError]`: sets or clears all three execute bits; refused on a read-only `Fs`.
- `fs.read_link(path: Str) -> Result[Str, IoError]`: the link's own text, not followed; an error if `path` is not a link.

- [ ] **Step 1: Tests** (both backends, Fs granted on a temp dir): `fs-copy` (copy, read back, executable bit carried), `fs-copy-replace`, `fs-copy-link-out` (destination is a link inside the grant pointing outside: `Err(Denied(..))`, target untouched), `fs-touch` (missing file created; existing file's `info().modified_ms` grows), `fs-set-executable` (on, then off, read through `info` or an `Exec` run), `fs-read-link` (a link's text; a plain file gives an error), and `fs-new-ro` (all three writes refused on `fs.read_only()`). Run: FAIL (unknown methods).
- [ ] **Step 2:** Implement end to end through the files above, each operation walked from the grant like `rename` and `info` (writes use the non-following walk for the destination name, so a final link is refused rather than followed). `copy` streams in 64 KB chunks and writes through a temp name then renames, so a failed copy leaves `to` as it was.
