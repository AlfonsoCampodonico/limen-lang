# A `yaml` module Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `src/std/yaml.lmn`, a YAML 1.2 reader and writer in Limen, passing the yaml-test-suite, with `yaml.encode` and `yaml.decode` written by the compiler as `json`'s are.

**Architecture:** A scanner turns text into tokens, a parser turns tokens into events (the spec's event model, as libyaml and the test suite use), and a composer turns events into `Node`s, resolving anchors, aliases, tags and the core schema. None of the three recurses per nesting level. `stringify` writes block style. `encode`/`decode` reuse the compiler's JSON derivation (`src/derive.ml`, `selfhost/derive.lmn`) over `yaml.Node`.

**Tech Stack:** Limen (src/std/), OCaml 5 (src/derive.ml), Limen (selfhost/derive.lmn), dune.

**Spec:** `docs/superpowers/specs/2026-11-27-yaml-design.md`

## Global Constraints

- YAML 1.2, core schema only; no YAML 1.1 booleans or merge keys.
- Nesting at most 512 levels; alias expansion at most 1,000,000 nodes per stream and 100 levels of alias within alias; each a named constant (`max_depth`, `max_alias_nodes`, `max_alias_depth`) in `yaml.lmn` and in SPEC.md.
- No recursion per nesting level anywhere in the module (parse, compose, stringify, `to_json`, `from_json`).
- Error messages start `line L, column C: `.
- Every change goes into both compilers and both backends; SPEC.md describes it in the same commit. Gate per task: `dune build --root .`, the focused tests, and a stage-1 self-hosted build when `selfhost/` changes; the full gate and Linux arm64 once, in Task 6.
- The yaml-test-suite data is downloaded only with the user's approval, vendored with its licence.
- Commit messages plain, no attribution of any kind; British spelling, no em dashes. Commit locally; never push.

## Review Focus

1. A tab used for indentation: an error naming the line, never a silent misread. Test `yaml-tab-indent` in Task 2.
2. A document with a byte-order mark and CRLF line endings (files saved on Windows): parses as the same document without them. Test `yaml-bom-crlf` in Task 2.
3. A string that looks like another type (`"no"`, `"1e3"`, `"null"`, `"0o17"`, `"2024-01-01"`, `"~"`, a leading `-` or `:`): `stringify` quotes it so it reads back as a `Str`. Test `yaml-stringify-quotes` in Task 4.
4. A key that repeats in one mapping, directly or through an alias: an error. Test `yaml-duplicate-key` in Task 3.
5. A very long plain scalar (1 MB on one line) and a 100,000-item sequence: linear time, under a second natively. Test `yaml-large` in Task 3.

### Task 1: The yaml-test-suite as test data, and its runner

**Files:**
- Create: `test/yaml-suite/` (the suite's `data-2022-01-17` release or newer: one directory per case with `in.yaml`, `in.json` when valid, `error` when invalid, `test.event`), `test/yaml-suite/LICENSE`, `test/yaml-suite/README.md` (where it came from and which version).
- Modify: `test/test_limen.ml` (a runner that, for each case, runs a Limen program built with `yaml.parse_all` and `json.stringify` over `yaml.to_json`, in both backends, and compares).
- Create: `src/std/yaml.lmn` with only the public types and functions stubbed to return `Err("not yet")`, so the runner compiles.

**Interfaces:**
- Produces: `pub enum Node { Null, Bool(Bool), Int(Int), Float(Float), Str(Str), Seq(List[Node]), Map(List[Pair]), Tagged(Str, Node) }`, `pub struct Pair { key: Node, value: Node }`, `pub fn parse(s: Str) -> Result[Node, Str]`, `pub fn parse_all(s: Str) -> Result[List[Node], Str]`, `pub fn stringify(n: Node) -> Str`, `pub fn to_json(n: Node) -> Result[json.Value, Str]`, `pub fn from_json(v: json.Value) -> Node`.

- [ ] **Step 1:** Ask the user for approval to download the suite (name, source `https://github.com/yaml/yaml-test-suite`, size); download into a new empty directory, check it, copy the data in.
- [ ] **Step 2:** Write the runner: counts `pass`, `fail`, and `skip` (cases whose JSON can't express the result: a non-string key, or no `in.json` for a valid case); prints `yaml-suite: P passed, F failed, S skipped of N`; a list `yaml_suite_known_failures` in the test file holds the case ids allowed to fail, and a case that fails without being listed, or passes while listed, fails the test `yaml-suite`.
- [ ] **Step 3:** Run it: every valid case fails (the stub); set the known-failures list to all of them for now.
- [ ] **Step 4:** Commit `test: the yaml-test-suite and a runner for it`.

### Task 2: Scanner and parser (text to events)

**Files:**
- Modify: `src/std/yaml.lmn` (scanner: block and flow indicators, the five scalar styles with folding and chomping, comments, directives `%YAML` and `%TAG`, document markers, BOM, CRLF; parser: events `StreamStart`, `DocStart`, `DocEnd`, `SeqStart(anchor, tag, flow)`, `SeqEnd`, `MapStart(anchor, tag, flow)`, `MapEnd`, `Scalar(anchor, tag, style, text)`, `Alias(name)`), private.
- Test: `test/test_limen.ml`: a second runner mode comparing the events against each case's `test.event` (the event format is fixed by the suite).

**Interfaces:**
- Produces (private to the module): `fn events(s: Str) -> Result[List[Event], Str]` with the event enum above, used by Task 3.

- [ ] **Step 1: Tests:** the event runner over the whole suite; `yaml-tab-indent`, `yaml-bom-crlf`, `yaml-error-position` (an unclosed flow sequence reports the line and column of its `[`).
- [ ] **Step 2:** Run: fail.
- [ ] **Step 3:** Implement the scanner as a loop over bytes with an explicit indentation stack, and the parser as a state machine with an explicit stack of states (the YAML spec's productions, as libyaml's `yaml_parser_state_t` does); depth past `max_depth` is an error.
- [ ] **Step 4:** Run: the event runner passes every case except those recorded in its own known-failures list, which must be under 5 % of the suite; each one listed with the reason.
- [ ] **Step 5:** Commit `yaml: scanner and parser, against the test suite's events`.

### Task 3: Composer (events to nodes), the core schema, limits

**Files:** `src/std/yaml.lmn` (`parse`, `parse_all`, `to_json`, `from_json`, accessors `get`, `at`, `as_str`, `as_int`, `as_float`, `as_bool`, `as_seq`, `pairs`), `SPEC.md` (a `yaml` section beside `json`).

**Interfaces:**
- Consumes: `events`.
- Produces: the public API of Task 1 working; `pub fn get(self: Node, key: Str) -> Option[Node]`, `pub fn at(self: Node, i: Int) -> Option[Node]`, `pub fn as_str(self: Node) -> Option[Str]` (and `as_int`, `as_float`, `as_bool`, `as_seq -> Option[List[Node]]`, `pairs -> Option[List[Pair]]`).

- [ ] **Step 1: Tests:** the JSON runner over the suite; `yaml-core-schema` (the 1.2 core schema's resolution table: `null`, `Null`, `NULL`, `~`, empty; `true`/`True`/`TRUE`; `0o17` is 15, `0x1F` is 31, `+12`, `-0`; `1.5`, `.5`, `1e3` and `-.inf`, `.NaN`; `yes`, `on`, `2024-01-01` and `0b1` stay `Str`); `yaml-tags` (`!!str 12` is `Str`, `!custom x` is `Tagged("!custom", Str("x"))`, `%TAG` handles expand); `yaml-aliases` (an alias copies its anchor's node); `yaml-billion-laughs` (nine levels of ten aliases: `Err` containing `aliases expand past the limit`, in under a second); `yaml-depth` (512 nested sequences parse, 513 is an error); `yaml-int-range` (an integer past `Int`'s range is an error); Review Focus `yaml-duplicate-key`, `yaml-large`; `yaml-k8s` (every file in `examples/k8s/` parses, and `parse_all` of a two-document manifest gives two nodes).
- [ ] **Step 2:** Run: fail.
- [ ] **Step 3:** Implement, composing with an explicit stack; aliases copy their node, charging its node count to the budget.
- [ ] **Step 4:** Run: the JSON runner's known-failures list shrinks to under 5 % of the suite, each listed with the reason.
- [ ] **Step 5:** Commit `yaml: parse and parse_all, the core schema, anchors and limits`.

### Task 4: `stringify`

**Files:** `src/std/yaml.lmn`, `SPEC.md`.

**Interfaces:**
- Produces: `stringify(n: Node) -> Str`: block style, two-space indent, `- ` items, `key: value`, a map or sequence inside a sequence item on the same line as the `- `; empty collections as `[]` and `{}`; multi-line strings as `|` block scalars (with `|-` or `|+` chomping matching the text); other strings plain unless plain style would resolve to something else or isn't allowed, then double-quoted with `json.quote`'s escapes; `Tagged(t, n)` writes the tag before the node; non-string keys use `? `.

- [ ] **Step 1: Tests:** `yaml-stringify-roundtrip` (for every valid suite case, `parse(stringify(parse(x)))` equals `parse(x)`), Review Focus `yaml-stringify-quotes`, `yaml-stringify-shape` (a fixed small document gives exactly the expected text).
- [ ] **Step 2:** Run: fail.
- [ ] **Step 3:** Implement without recursion (an explicit stack, as `json.stringify` does).
- [ ] **Step 4:** Run: pass.
- [ ] **Step 5:** Commit `yaml: stringify`.

### Task 5: `yaml.encode` and `yaml.decode`

**Files:** `src/derive.ml` and `selfhost/derive.lmn` (recognise `yaml.encode`/`yaml.decode` as they do `json`'s, generating conversions over `yaml.Node`), `src/std/yaml.lmn` (`encode[T]`, `decode[T]` as `json.lmn`'s are declared), `SPEC.md` (the rules: same types and E0212 cases as `json`, struct fields as string keys, enums as `json` writes them).
- Test: `test/test_limen.ml`.

**Interfaces:**
- Produces: `pub fn encode[T](x: T) -> Str`, `pub fn decode[T](s: Str) -> Result[T, Str]`.

- [ ] **Step 1: Tests** (both backends): `yaml-encode-struct` (`Todo { id: 1, title: "no", done: false }` gives text that `decode` reads back equal, with `title: "no"` quoted), `yaml-decode-errors` (the same path-naming messages as `json.decode`: "`todos[2].title`: expected a string, found an integer"), `yaml-decode-option` (a missing `Option` field is `None`), `yaml-encode-e0212` (a struct holding `Fs` is E0212), `yaml-decode-kubeconfig` (a kubeconfig with clusters, users and contexts decodes into structs with `Option` fields).
- [ ] **Step 2:** Run: fail.
- [ ] **Step 3:** Implement, sharing the JSON derivation's walk with a parameter for the target module.
- [ ] **Step 4:** Run: pass; build stage 1.
- [ ] **Step 5:** Commit `yaml.encode and yaml.decode, written by the compiler`.
