# Task 32-calculator

Write a complete Writ program (`fn main`) for this task. Output must match exactly, including the final newline.

Run it as: `writ run solution.wr` (from this task's directory).

Write a tokenizer and an evaluator for integer arithmetic with + - * / and parentheses, respecting precedence (/ is integer division). Evaluate and print, one per line: "2 + 3 * 4", "(2 + 3) * 4", "100 / 7 - 2", "2 * (3 + (4 - 1)) * 5".
