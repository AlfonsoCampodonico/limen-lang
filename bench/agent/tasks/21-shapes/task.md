# Task 21-shapes

Write a complete Limen program (`fn main`) for this task. Output must match exactly, including the final newline.

Run it as: `limen run solution.lmn` (from this task's directory).

Define an enum Shape with Circle(Float) (radius), Rect(Float, Float) and Square(Float). Using 3.0 for pi, print the area of Circle(2.0), Rect(3.0, 4.5) and Square(1.5), one per line, printed with Limen's normal Float formatting.
