# Task 28-traffic-light

Write a complete Tessera program (`fn main`) for this task. Output must match exactly, including the final newline.

Run it as: `tessera run solution.tsr` (from this task's directory).

Model a traffic light as an enum Light with Red, Green, Yellow and `fn next(l: Light) -> Light` (Red -> Green -> Yellow -> Red). Starting at Red, print 7 states, one per line.
