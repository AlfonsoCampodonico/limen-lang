# Task 27-tree-depth

Write a complete Tessera program (`fn main`) for this task. Output must match exactly, including the final newline.

Run it as: `tessera run solution.tsr` (from this task's directory).

Define a binary tree enum (Leaf, Node(Tree, Int, Tree)). Insert 50, 30, 70, 20, 40, 60, 80, 35 into a binary search tree, then print the in-order traversal in Tessera's list format and, on the next line, the height (a single node has height 1).
