# Task 22-safe-divide

Write a complete Tessera program (`fn main`) for this task. Output must match exactly, including the final newline.

Run it as: `tessera run solution.tsr` (from this task's directory).

Write `fn divide(a: Int, b: Int) -> Option[Int]` that returns None for division by zero. For (10, 2), (7, 0), (9, 3), print the result with Tessera's default formatting (e.g. `Some(5)`).
