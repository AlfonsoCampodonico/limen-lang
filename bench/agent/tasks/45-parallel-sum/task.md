# Task 45-parallel-sum

Write a complete Vela program (`fn main`) for this task. Output must match exactly, including the final newline.

Run it as: `vela run solution.vela` (from this task's directory).

Using a `group`, start 4 tasks: task k (k = 0..3) sums the integers from k*250000+1 to (k+1)*250000. Print the four partial sums in Vela's list format, then the total on the next line.
