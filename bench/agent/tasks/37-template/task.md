# Task 37-template

Write a complete Tessera program (`fn main`) for this task. Output must match exactly, including the final newline.

Run it as: `tessera run solution.tsr` (from this task's directory).

Given the template "Hello {name}, you have {count} new {thing}." and the pairs name=Ada, count=3, thing=messages, replace each `{key}` with its value and print the result. Note: in Tessera source a literal brace in a string is written `\{`.
