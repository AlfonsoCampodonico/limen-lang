# Task 37-template

Write a complete Limen program (`fn main`) for this task. Output must match exactly, including the final newline.

Run it as: `limen run solution.lmn` (from this task's directory).

Given the template "Hello {name}, you have {count} new {thing}." and the pairs name=Ada, count=3, thing=messages, replace each `{key}` with its value and print the result. Note: in Limen source a literal brace in a string is written `\{`.
