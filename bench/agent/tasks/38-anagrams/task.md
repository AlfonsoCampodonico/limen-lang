# Task 38-anagrams

Write a complete Vela program (`fn main`) for this task. Output must match exactly, including the final newline.

Run it as: `vela run solution.vela` (from this task's directory).

Group ["listen", "silent", "enlist", "google", "gooegl", "cat", "act", "tac", "dog"] into anagram groups. Print each group on its own line, words separated by spaces, groups ordered by their first word's position in the input.
