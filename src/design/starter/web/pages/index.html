How it works

Three files to know

Everything else is plain HTML and CSS.

  1. 01

    Routes

    Each route is a method, a path and a function that answers it. A path with no route is a 404.

    main.lmn
    fn routes(s: Site) -> List[http.Route] {    [        http.on("GET /", |r, p| page(s, "Home", "index.html")),        http.on("GET /about", |r, p| page(s, "About", "about.html")),    ]}
  2. 02

    Grants

    The program can only listen on the address limen.toml grants it. It reads no files when it runs: the pages are built in.

    limen.toml
    [grants]listen = "127.0.0.1:8080"
  3. 03

    Running it

    Run it while you work on it, test it, then build one binary to deploy.

    terminal
    $ limen test main.lmn
3 tests, 0 failed (1ms)
$ limen run main.lmn
serving on http://127.0.0.1:8080
